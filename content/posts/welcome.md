## 不需要标准答案

这是博客的初始使用说明，可以在开始写作后修改或删除。

一篇笔记不必很长。今天理解的一个概念、运行成功的一段代码、读书时记下的一句话，都可以成为一篇文章。

## 写下第一篇

点击网站上的 **写笔记**，填写标题和正文，下载 Markdown 文件，再上传到 GitHub 仓库中的 `content/posts` 文件夹。

提交后，GitHub Actions 会重新生成博客。只有你或有仓库写入权限的人可以发布和修改文章。

写作页面里的内容暂时存在当前页面中，离开前请先下载保存。

## 让笔记更清楚

你可以用 Markdown 写标题、列表、引用、代码和图片。

- 写下知识点。
- 用自己的话解释它。
- 留下实践中的发现。
- 标记以后要继续研究的问题。

> 不急着写得漂亮，先写得真实。

下面是一段代码的展示效果：

```python
# 每天一点点，积累会有形状。
notes = ["学习", "实践", "回顾"]
for note in notes:
    print(note)
```

## 给自己留一个索引

分类适合大的学习方向，标签适合跨文章的关键词。文章会自动进入日期归档，也可以通过搜索找到正文里的内容。

每篇文章都有独立的网址，可以直接分享给别人。

## 阅读时听一点音乐

## 留下未完成的问题

学习笔记也可以记录“不懂”。在文末留下下一步：

- [x] 写下今天的收获
- [ ] 用一个小例子验证自己的理解
- [ ] 几天后回来，补上新的想法
