## 不需要标准答案

这是博客的初始使用说明，可以在开始写作后修改或删除。

一篇笔记不必很长。今天理解的一个概念、运行成功的一段代码、读书时记下的一句话，都可以成为一篇文章。

## 写下第一篇

点击网站上的 **写一篇**，填写标题和正文，下载 Markdown 文件，再上传到 GitHub 仓库中的 `content/posts` 文件夹。

提交后，GitHub Actions 会重新生成博客。只有你或有仓库写入权限的人可以发布和修改文章。

写作页面会自动保存多份草稿，刷新后可以继续写。草稿和图片保存在当前浏览器，不会同步到其他设备；重要内容请导出备份。

编辑区支持 Markdown 实时预览。插入本地图片后，点击「下载笔记」自动打包 ZIP，解压，把文章上传到 `content/posts`，图片上传到 `public/images`。

## 让笔记更清楚

你可以用 Markdown 写标题、列表、引用、代码和图片。

- 写下知识点。
- 用自己的话解释它。
- 留下实践中的发现。
- 标记以后要继续研究的问题。

> 不急着写得漂亮，先写得真实。

下面是一段代码的展示效果：

```python
# 每天一点点，积累会有形状。
notes = ["学习", "实践", "回顾"]
for note in notes:
    print(note)
```

## 把公式与系列写进笔记

行内公式可以写成 `$E = mc^2$`，效果是 $E = mc^2$。独立公式用两对美元符号包裹：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

在「文章设置」中填写「系列名称」，可以把多篇笔记串起来；使用相同的系列名称，再为每篇填写序号，网站会自动生成系列目录。

## 从不同页面找到自己的记录

**笔记**页可以搜索和筛选文章，**专题**页按分类和系列浏览。

还没有发布的内容保存在**草稿**页，点击标题即可继续写。**写一篇**会创建新笔记；发布步骤可以在**发布指南**中查看。

## 给自己留一个索引

分类适合大的学习方向，标签适合跨文章的关键词。文章会自动进入日期归档，也可以通过搜索找到正文里的内容。

每篇文章都有独立的网址，可以直接分享给别人。

## 阅读时听一点音乐

顶部导航中的「音乐」会打开独立的播放器页面，默认不会自动播放。你可以播放初始歌单，也可以选择电脑里的本地歌曲。选择的本地歌曲只在你自己的浏览器里播放，不会上传。

## 留下未完成的问题

学习笔记也可以记录“不懂”。在文末留下下一步：

- [x] 写下今天的收获
- [ ] 用一个小例子验证自己的理解
- [ ] 几天后回来，补上新的想法
